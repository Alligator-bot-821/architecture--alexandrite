# Мотивация
Мониторинг позволит своевременно обнаружить проблемные места в системе, что поможет оперативно решить возникшую проблему, вовремя масштабировать сервис или обнаружить падение одного из компонентов сервиса.
Мониторинг в целом поможет повысить стабильность и отказоустойчивость всей системы.
В итоге улучшится пользовательский опыт, можно уменьшить задержки получения данных по АПИ что приведет к положительному результату работы пользователей с сервисом и сократит количество жалоб.


# Выбор подхода к мониторингу
USE - будем использовать для очередей и для баз данных. Позволит увидеть насколько нагружены компоненты и на основе показателей делать масштабирование компонентов
RED - используем для Shop API, CRM API, MES API. Эти показатели позволят понять какое АПИ можно оптимизировать, включить кэширование, горизонтально масштабировать. Поможет избежать сбоев, и поможет прогнозировать сколько требуетя ресурсов


# Метрики

### RabbitMQ
* Number of dead-letter-exchange letters in RabbitMQ - количество необработанных сообщений
* Number of message in flight in RabbitMQ - количество сообщений в очереди

### shop API
* Number of requests (RPS) for internet shop API - поможет отслеживать нагрузку на приложение
* CPU % for shop API - отслеживание нагрузки по загрузке в процентах процессора
* Memory Utilisation for shop API - потребление памяти
* Response time (latency) for shop API - время отвера запросов приложения
* Number of HTTP 200 for shop API - удачные ответы приложения
* Number of HTTP 500 for shop API - ошибки ответа приложения, помогает отслеживать ошибки и быстро реагировать


### CRM API
используем такие же метрики что и для shop API


### MES API
используем такие же метрики что и для shop API


### shop db
* Memory Utilisation for shop db instance - помогает контролировать потребление памяти
* Size of shop db instance - контролирует размер хранилища для БД
* Number of connections for shop db instance - количество соединений с БД


### MES db
* Size of MES db instance - контролирует размер хранилища для БД
* Number of connections for MES db instance - количество соединений с БД
* Memory Utilisation for MES db instance - помогает контролировать потребление памяти 


### S3 storage
* Size of S3 storage - позволяет следить за ресурсами хранилища для своевременного увеличения
